# Hackathon otevřených dat Karlovarského kraje 2026

9.–10. 10. 2026 · Fakulta ekonomická ZČU, Cheb · [Pravidla soutěže](https://kickk.cz/wp-content/uploads/2026/09/Hackathon-2026-Pravidla-souteze.pdf)

## Než začnete
- Tým potřebuje alespoň jeden účet na GitHubu, pod kterým repozitář založí. Účet doporučujeme každému, kdo bude psát kód.
- Doporučujeme skrýt e-mail v commitech: Settings → Emails → Keep my email addresses private.

## 1. Založte repozitář
1. Otevřete [project-template](https://github.com/opendata-hackathon-kk/project-template) a klikněte na **Use this template → Create a new repository**.
2. Owner: účet jednoho člena týmu. Název podle projektu, malými písmeny bez diakritiky (např. `cyklomapa-kv`).
3. Členy s vlastním účtem přidejte v **Settings → Collaborators → Add people**.

## 2. Během práce
- Vyplňte README podle šablony, včetně použitých dat a použití AI.
- Použijte alespoň jednu datovou sadu z [Katalogu otevřených dat na DATAZÁPAD](https://www.datazapad.cz/search?collection=dataset&layout=grid). U každé uveďte poskytovatele, odkaz a licenci.
- Do `LICENSE` doplňte jména všech autorů. Výchozí licence je MIT, jinou volte jen z: Apache-2.0, EUPL-1.2, GPL-3.0, AGPL-3.0.
- Hesla, API klíče ani tokeny do repozitáře nikdy nevkládejte.

## 3. Odevzdání do 10. 10. 2026, 17:00
1. Přepněte repozitář na **Public**: Settings → Danger Zone → Change visibility.
2. Označte odevzdanou verzi: **Releases → Create a new release → Choose a tag**, napište `hackathon-2026`, zvolte **Create new tag** a klikněte na **Publish release**.
3. Vyplňte [formulář odevzdání](https://forms.cloud.microsoft/Pages/ResponsePage.aspx?id=VEtKVyJh602bGMWP18ddMvScdTNCNitFkvFh7MBnceZUQkpONjFGN1pOUEU4NFlUNUNZV0s2WlpSOC4u), jeden za tým.

Za odevzdanou verzi se považuje stav označený tagem `hackathon-2026`.

## Po odevzdání
Organizátor uloží kopii projektu jako archiv do organizace [opendata-hackathon-kk](https://github.com/opendata-hackathon-kk) na GitHubu. Repozitář i autorská práva zůstávají vám.

Během akce se obraťte na organizátory na místě. Pokud formulář nefunguje, pošlete odkaz na repozitář na jan.sklepek@kickk.cz.
